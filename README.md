## Quick setup

### If you've done this kind of thing before:

```bash

git clone https://github.com/akpattnaiksre/customALZ.git

# SSH
git clone git@github.com:akpattnaiksre/customALZ.git
```

### Or create a new repository on the command line:

```bash
echo "# customALZ" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/akpattnaiksre/customALZ.git
git push -u origin main
```
